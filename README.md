# Personal Portfolio Website

A responsive personal portfolio website built with **HTML** and **CSS**, hosted with **GitHub Pages**.

## Sections
- **Home:** name, profile picture and introduction
- **About Me:** education (table) and interests (lists)
- **Skills:** technical skills
- **Projects:** CaterEase, Exam Scores Analyser, Office Network Design
- **Contact:** email and contact form

## Technologies
HTML5 (semantic elements), external CSS, Flexbox, CSS Grid, media queries, Git and GitHub Pages.
